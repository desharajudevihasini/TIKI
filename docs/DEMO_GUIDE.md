# Demo checklist

1. Show the hardware: ESP32-S3, camera, camera-only button, visible LED, speaker.
2. Press **Talk to TIKI** in the app and ask what TIKI can do; let the actual hardware speaker respond.
3. Ask TIKI to look at an object, aim the glasses, then tap the physical **camera** button. Show the actual saved JPEG and spoken description.
4. Open the Photos library and ask about an earlier image to demonstrate visual memory.
5. Explain that the Mac currently supplies the microphone and AI gateway, while the wearable captures photos and produces sound.

Record actual hardware behavior. If editing out waiting time, mark cuts clearly rather than misrepresenting events as one uninterrupted interaction. Keep API keys, Wi-Fi passwords, and private saved photos out of footage.

Place your real hardware images in `docs/` and add the demo video link to README when ready.
